# Tipover
TipOver is a single-player logic puzzle game where the goal is to navigate a character (called the Tipper) across a grid of stacked crates by strategically tipping them over to create a path.

- The game is played on a grid.
- Different crates at different heights are placed on the board.
- The Tipper starts on top of one crate.

When a crate is tipped:
- It falls in one direction (up, down, left, or right).
- It must land in empty spaces only.
- The fallen crate becomes a bridge/path.

Rules! 
- You can only tip a crate if there is enough empty space for it to fall.
- Crates fall in a straight line equal to their height.
- You cannot move diagonally or jump gaps.
- Each crate can only be tipped once.

Have Fun!
